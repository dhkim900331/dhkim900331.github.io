# 1. Overview

다년간 사용하던 ChatGPT 에서 Claude Code로 뒤늦게 전환하여 기능을 다뤄보고,

AI Toolkit 기능을 확인하고자 전체 코드 리팩토링을 맡겼다.

<br>


# 2. Descriptions

ChatGPT 도 매우 훌륭하지만 다른 AI 를 활용해본바도 거의 없고

항상 궁금해만 하던 Claude 를 써보고자 GPT 구독은 잠시 멈추고, 곧바로 Claude Pro 를 결제 했다.

Pro Level 부터 Claude Code를 사용할 수 있기 때문이다.

<br>

MSW 가이드에 따라, 내 바람의나라 프로젝트 폴더를 위해 API Key 생성과 `.mcp.json` 을 준비하고 (수동 및 자동 모두 가능)

Claude Desktop App의 Code 메뉴에서 내 프로젝트 폴더를 선택하면 Agent가 설치된다.

> 사전에 git for Windows 도 설치해야 한다. Code가 git을 통해 명령어를 전달한다고 한다.

<br>

AI Toolkit (MSW 내에서 활성화) 실행하면 Claude code와 연결되는 CLI 가 활성화 되고,

Claude Code Desktop App에서 채팅만으로 프로젝트에 대해 여러 요구를 전달하면 사용자 동의를 얻어가며 알아서 작업을 한다.

<br>

첫번째로 전체 코드가 사실상 GPT 의견을 받아 스스로 개발한 코드다 보니, 잘못된 부분이 있을 것으로 짐작하여

1. 전체 코드 한글 주석 풍부하게
2. 표준 코드 개발론에 따라, Entity/Component name 표준화 및 메서드/변수 이름 표준화
3. Decoupling 방식으로 최대한 코드 쪼개기

우선 위와 같이 리팩토링을 요청했고, Pro 기준 2~30% 토큰이 소모되어 완료되었다.

<br>

그 후, 현재 맵 시스템 점검하고 캐릭터의 이동이 바람의나라 타일 기반 움직임처럼 구현을 좀 더 요청하고

카메라 워킹도 바람의나라 처럼 타일 기반 및 캐릭터를 중심으로 두게 하고, 맵 바깥 영역을 보여주지 않게 요청했다.

해당 부분도 금방 작업이 완료되었다.

<br>

내가 프롬프트를 정말 상세히 쓰면 쓸수록 불필요한 토큰 낭비없이 똑똑하게 자동으로 일을 하는것도 훌륭하지만

GPT를 다년간 써본 것과 잠깐 Claude 쓴것을 비교해보자면, GPT는 스스로 잘못된 길을 간 경우 그 함정에서 빠져나오지 못하지만

Claude는 토큰을 좀 더 쓰는게 아쉽지만 자신이 좀 더 판단하고 잘못된 길이라는것을 인지하면 회귀 하여 문제를 수정하려는 태도가

유독 눈에 띈다.

<br>

앞으로 좀 더 사용자는 에셋/스프라이트 중심의 자료와 튼튼한 프롬프트를 준비하여

Cluade에게 전달하여 빠른 개발을 해보려고 한다.
